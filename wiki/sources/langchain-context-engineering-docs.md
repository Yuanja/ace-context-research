# LangChain Context Engineering Docs

LangChain defines context engineering as providing the right information and tools in the right format so an LLM can accomplish a task. The docs separate context into model context, tool context, and lifecycle context, and distinguish transient state from persistent store.

Relevance to ACE: this is practitioner framing rather than ACE validation, but it gives a useful production vocabulary for monitoring where context enters, mutates, persists, and affects behavior.
