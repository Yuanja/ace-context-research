# Addressable Recall Compaction

## Citation

Yuma Ichikawa et al. "Addressable Recall Compaction for Long Context-Window Control in AI Agents." arXiv:2607.25066, submitted 2026-07-27.

## Core Claim

ARC separates archival storage from active-context presentation. Tool observations are stored verbatim in an append-only, addressable store; the active context keeps compact citations that can be dereferenced with recall tools.

## Method

- Store each tool observation under a stable content-derived identifier.
- Replace older or longer observations in the active transcript with citation stubs containing previews, metadata, and recall hints.
- Let the agent explicitly recall `§id` entries when exact prior content matters.

This differs from RAG memory because recovery is address-based rather than similarity-dependent.

## Evaluation Notes

The paper reports:

- Needle-in-Haystack exact-answer accuracy: 99.40% for ARC versus 88.12% for the best evaluated baseline.
- LongBench-v2 Hard average accuracy: 29.97% for ARC versus 28.25% for the best evaluated baseline.
- Lower estimated serving time and HBM traffic under the paper's hardware-cost model.

These claims are for the tested Qwen3-8B/32B settings and should not be generalized to all retrieval or compression systems.

## Limitations

The authors note the margin narrows on LongBench-v2 because those tasks require synthesis, not just exact recall. Open questions include token overhead, generalization beyond Qwen3 models, and broader model/context-window grids.
