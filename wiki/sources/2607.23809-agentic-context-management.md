# ACM: Agentic Context Management

## Citation

Xiaochuan Li et al. "ACM: Agentic Context Management for Long Horizon Tasks." arXiv:2607.23809, submitted 2026-07-26.

## Core Claim

ACM equips agents with context-editing tools so the agent can decide when to compress active context, offload raw messages to external memory, and retrieve them later.

## Method

ACM introduces two tools:

- `manage_context`: compresses previous turns into a concise summary and stores the raw messages externally.
- `query_memory`: retrieves information from the raw stored messages using the summary identifier.

The key distinction from a summary-only agent is that raw content is preserved outside the active prompt, and the agent initiates context management based on its reasoning state rather than a fixed usage threshold.

## Evaluation Notes

The paper evaluates agentic search and coding tasks. It reports that context management reduces peak token pressure, allows longer exploration, and improves consistency across independent trials. The abstract says the post-training pipeline improves Qwen3.5-9B search and coding performance over ReAct; detailed benchmark tables should be consulted before quoting exact numbers.

## Limitations

The authors state ACM presupposes strong long-horizon reasoning and tool-use ability; weaker models may fail or hallucinate too early to benefit from compression. The paper is fresh and should be treated as credible but not yet broadly validated.
