# Agentic Context Management

ACM focuses on active transcript control during long-horizon tasks. Instead of fixed-threshold summarization, the agent decides when to compress, stores raw context externally, and queries it later.

The important distinction is lifecycle control: context management is an action inside the agent loop rather than an external cleanup policy.
