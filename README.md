# ACE Context Research

LLM-maintained research wiki for Agentic Context Engineering and adjacent context-management techniques.

## Browser Viewer

Open `site/index.html` locally in a regular browser, or use the GitHub Pages deployment when enabled.

Rebuild the viewer:

```bash
node tools/build-viewer.js
```

Run the viewer build test:

```bash
node --test tests/viewer-build.test.js
```
